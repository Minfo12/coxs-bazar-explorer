# Cox's Bazar Explorer — Free MVP

Android-friendly static website for exploring Cox's Bazar.

## Files
- `index.html` — website
- `style.css` — design
- `app.js` — search, filters, modal, map
- `data.js` — destination data

## Free publishing
1. Create a GitHub account.
2. Create a new public repository named `coxs-bazar-explorer`.
3. Upload all four website files plus this README.
4. GitHub → Settings → Pages → Deploy from branch → `main` → `/root`.
5. Open the generated `github.io` address.

The map uses Leaflet and OpenStreetMap tiles. Check OpenStreetMap tile usage policy before heavy/commercial traffic.

## Important
This MVP intentionally labels some locations as `Hidden Gem` or `Needs Verification`. Before publishing them as official tourist destinations, verify access, GPS, safety, ownership and local authority information.
